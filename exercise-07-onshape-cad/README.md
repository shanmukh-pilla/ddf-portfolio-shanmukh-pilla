# Exercise 07: Onshape CAD Self-Study

## Overview

This exercise focused on learning the fundamentals of Computer-Aided Design (CAD) using the Onshape cloud-based CAD platform. The objective was to complete the required self-paced training modules and gain an understanding of parametric modelling, sketch creation, and part design workflows commonly used in digital fabrication and engineering design.

Unlike the previous exercises, which focused on electronics, sensors, actuators, and embedded systems, this exercise introduced digital design tools used for creating and modifying 3D models before fabrication.

The exercise required completion of the following three courses:

- Introduction to Parametric Feature-Based CAD
- Introduction to Sketching
- Introduction to Part Studios

Through these training modules, I developed a foundational understanding of CAD modelling principles and gained practical experience using the Onshape platform.

---

# Course 1 – Introduction to Parametric Feature-Based CAD

## Objective

The objective of this course was to understand the core principles of parametric modelling and feature-based design.

## Learning Activities

During this module, I learned how CAD models are built using editable parameters and feature histories. The training demonstrated how dimensions, constraints, and modelling operations are linked together so that designs can be modified efficiently without rebuilding them from scratch.

## Key Learning Outcomes

- Understanding parametric modelling concepts
- Feature-based design methodology
- Design intent and model history
- Editable dimensions and parameters
- Associative geometry relationships

## Reflection

This module provided a strong introduction to how professional CAD software operates. Understanding parametric modelling helped me appreciate how engineers can efficiently modify and improve designs throughout the development process.

---

# Course 2 – Introduction to Sketching

## Objective

The objective of this course was to learn how sketches are created and constrained within Onshape and how they serve as the foundation for 3D models.

## Learning Activities

In this module, I worked with various sketching tools and learned how to create:

- Lines
- Circles
- Rectangles
- Arcs
- Construction Geometry

I also learned how dimensions and geometric constraints are applied to maintain accuracy and design intent.

## Key Learning Outcomes

- Sketch creation tools
- Geometric constraints
- Dimensional constraints
- Fully defined sketches
- Design accuracy and consistency

## Reflection

This course improved my understanding of how CAD models are built from sketches. Learning how to properly apply dimensions and constraints helped me better understand the importance of precision in engineering design.

---

# Course 3 – Introduction to Part Studios

## Objective

The objective of this course was to learn how sketches are transformed into three-dimensional parts using Onshape's modelling tools.

## Learning Activities

This module introduced the Part Studio environment and demonstrated how solid geometry is created using modelling features such as:

- Extrude
- Revolve
- Fillet
- Chamfer
- Hole
- Shell

I learned how sketches are converted into 3D objects and how additional modelling operations can be used to refine and modify designs.

## Key Learning Outcomes

- Part Studio workflow
- Solid modelling techniques
- Feature creation and editing
- Geometry modification tools
- Model organisation and management

## Reflection

This course helped me understand how sketches evolve into complete 3D models. It connected the concepts learned in the previous modules and demonstrated how professional CAD models are developed.
